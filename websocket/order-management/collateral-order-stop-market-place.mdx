The `result` object adds the activation fields and the position fields to the standard order object — see the [order object reference](/websocket/order-management/overview#order-object). A margin stop-market order reports `type` `10` with `price` `"0"`.

<Warning>A per-market ceiling limits how many stop-market orders one account can hold. Reaching it returns error `103` — cancel an existing stop before placing another. For a stop that tracks the position size automatically rather than a fixed amount, use [`collateral_order_tpsl_place`](/websocket/order-management/collateral-order-tpsl-place) instead.</Warning>

## Update frequency

This method is client-initiated: the server answers each `collateral_order_stop_market_place` request with a single response frame carrying the same `id`. Subscribe to [Orders Pending](/websocket/account-streams/orders-pending) to observe the trigger firing.
