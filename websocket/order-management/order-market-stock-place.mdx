Place a spot market order sized in the base asset on both sides. The matching behaviour is identical to [`order_market_place`](/websocket/order-management/order-market-place); the difference is that `amount` is always [stock](/glossary#stock), on a buy as well as on a sell. This method suits sizing logic expressed in coins rather than in quote currency.

The `result` object is the standard order object — see the [order object reference](/websocket/order-management/overview#order-object). This method reports `type` `202` and `price` `"0"`.

<Warning>A buy still consumes quote currency even though the order is sized in stock. The balance must cover `amount` multiplied by the best ask, plus fee, otherwise the order fills only partially. The `deal_money` field reports what the fill actually cost.</Warning>

## Update frequency

Client-initiated. The server answers each `order_market_stock_place` request with a single response frame carrying the same `id`.
