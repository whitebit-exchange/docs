## Place margin market order

### Request parameters

<WsSchemaTable fields={collateralOrderMarketPlaceParams} />

No money-denominated variant exists for this family. Unlike spot, `amount` is [stock](/glossary#stock) on both sides, which is why there is no `collateral_order_market_stock_place` — this method already behaves that way.

<WsMessageExample data={exCollateralOrderMarketPlaceRequest} />

### Response

<WsMessageExample data={exCollateralOrderMarketPlaceResponse} />

The `result` object is the standard order object plus `reduce_only` and `position_side` — see the [order object reference](/websocket/order-management/overview#order-object). A margin market order reports `type` `8` and `price` `"0"`.

<Warning>Set `reduce_only` when closing a position. Without it a stale size larger than the open position flips the position instead of flattening it. With the flag set, an order that would flip is rejected with error `115`, and an order with nothing to reduce is rejected with error `116` or dropped with status `AUTO_CANCELED_REDUCE_ONLY`.</Warning>

## Update frequency

This method is client-initiated: the server answers each `collateral_order_market_place` request with a single response frame carrying the same `id`. Subscribe to [Positions](/websocket/account-streams/positions) to confirm the resulting position size.
