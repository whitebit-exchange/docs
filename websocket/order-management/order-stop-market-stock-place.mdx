Fire a market order sized in the base asset when the market reaches `activation_price`. The trigger semantics match [`order_stop_market_place`](/websocket/order-management/order-stop-market-place); only the unit of `amount` differs — here it is [stock](/glossary#stock) on a buy as well as on a sell.

The `result` object adds the conditional fields to the standard order object — see the [order object reference](/websocket/order-management/overview#order-object). This method reports `type` `203`, the stock-denominated stop-market code.

<Warning>A buy spends quote currency at activation even though the order is sized in stock. The balance must cover `amount` multiplied by the best ask at trigger time, plus fee.</Warning>

## Update frequency

This method is client-initiated: the server answers each `order_stop_market_stock_place` request with a single response frame carrying the same `id`. Subscribe to [Orders Pending](/websocket/account-streams/orders-pending) to observe the trigger firing.
