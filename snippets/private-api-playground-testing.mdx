Each private API reference page includes an **HMAC request signer** that computes and sends authenticated requests directly from the browser.

**To test a private endpoint:**

<Steps>
  <Step title="Scroll to the HMAC request signer">
    The signer appears on every private endpoint page below the endpoint description.
  </Step>
  <Step title="Enter the API key and secret">
    The signer keeps credentials in browser memory only — never written to `localStorage` or cookies.
    Reloading the page clears all stored credentials.
  </Step>
  <Step title="Fill in the endpoint parameters">
    Each field appears as a labeled input. For endpoints without a schema, enter parameters as a JSON object.
    The signer adds `request`, `nonce`, and `nonceWindow` automatically — omit these fields from the input.
  </Step>
  <Step title="Click Send request">
    The signer computes `X-TXC-PAYLOAD` and `X-TXC-SIGNATURE` fresh for each request,
    then dispatches the call and shows the response inline.
  </Step>
</Steps>

<Info>
  The signer computes `X-TXC-PAYLOAD` and `X-TXC-SIGNATURE` in-browser on every send.
  Click **Compute headers** first to preview the values, then **Send request** to dispatch.
</Info>
