## Overview

When a deposit is detected as Travel Rule-eligible, it becomes ready for verification. Use this endpoint to submit the required originator data to proceed with the verification process.

---

## Submission Scenarios

### Scenario 1: Individual from Hosted Wallet (VASP in list)

Use when the sender is a natural person sending from an exchange or custodian that appears in the [VASPs list](/api-reference/travel-rule/get-vasps).

**Required fields:**
- `walletType`: `"hosted"`
- `originator.type`: `"individual"`
- `originator.firstName`, `originator.lastName`
- `originator.residenceCountry`, `originator.walletAddress`, `originator.address`
- `originatingVasp.vaspId`

### Scenario 2: Entity from Hosted Wallet (VASP not in list)

Use when the sender is a legal entity sending from an exchange or custodian not in the VASPs list.

**Required fields:**
- `walletType`: `"hosted"`
- `originator.type`: `"entity"`
- `originator.fullName`
- `originator.residenceCountry`, `originator.walletAddress`, `originator.address`
- `originatingVasp.vaspName`

### Scenario 3: Individual from Unhosted Wallet

Use when the sender is a natural person sending from a self-custody wallet (hardware wallet, software wallet).

**Required fields:**
- `walletType`: `"unhosted"`
- `originator.type`: `"individual"`
- `originator.firstName`, `originator.lastName`
- `originator.residenceCountry`, `originator.walletAddress`, `originator.address`

<Note>
No `originatingVasp` is required for unhosted wallets.
</Note>

## Field Requirements by Wallet and Party Type

| Field | Hosted + Individual | Hosted + Entity | Unhosted + Individual | Unhosted + Entity |
|-------|---------------------|-----------------|----------------------|-------------------|
| `firstName` | Required | - | Required | - |
| `lastName` | Required | - | Required | - |
| `fullName` | - | Required | - | Required |
| `originatingVasp` | Required | Required | - | - |

---

## Address Requirements

All address objects require:
- `country` - ISO 3166-1 alpha-3 code (e.g., `"NLD"`, `"DEU"`)
- `city` - City name
- `addressLine1` - Street address

Optional:
- `postCode` - Postal code

---

## Verification Status

After successful submission, the response contains a `status` field:

| Status | Description |
|--------|-------------|
| `submitted` | Data submitted, awaiting compliance review |
| `approved` | Immediately approved (rare) |
| Other | Various review statuses |

<Note>
Monitor the deposit status via [deposit/withdraw history](/api-reference/account-wallet/get-deposit-withdraw-history) to track when the deposit is credited or rejected.
</Note>

---

## Common Errors

<Warning>
**Transaction Not Found**: Ensure the `uniqueId` matches a transaction in your deposit history. The transaction must exist and belong to your account.
</Warning>

**Transaction not ready for verification:**
The deposit must be ready for verification. If the deposit is not in the correct state or has already been processed, this error is returned.

**Missing VASP for hosted wallet:**
When `walletType` is `"hosted"`, you must provide either `vaspId` (if VASP is in the list) or `vaspName` (if not in the list).

## Integration Workflow

```javascript
// 1. Find deposits ready for verification
const history = await getDepositHistory();
const depositForVerification = history.find(d => d.requiresVerification);

// 2. Get available VASPs
const { data: { vasps } } = await getVasps();

// 3. Determine VASP reference
const originatingVaspName = "Binance"; // From user input
const knownVasp = vasps.find(v => v.name === originatingVaspName);
const originatingVasp = knownVasp
  ? { vaspId: knownVasp.vaspId }
  : { vaspName: originatingVaspName };

// 4. Submit verification
const response = await submitDepositVerification({
  uniqueId: depositForVerification.unique_id,
  walletType: "hosted",
  originator: {
    type: "individual",
    firstName: "Alice",
    lastName: "Johnson",
    residenceCountry: "NLD",
    walletAddress: depositForVerification.address,
    address: {
      country: "NLD",
      city: "Amsterdam",
      addressLine1: "Damrak 1"
    }
  },
  originatingVasp
});

console.log(`Verification status: ${response.data.status}`);
```
