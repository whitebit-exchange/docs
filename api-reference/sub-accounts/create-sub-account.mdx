<Note>
The `email` field, not `shareKyc`, decides whether the sub-account is active at creation:
- When `shareKyc` is `false` or not provided: `email` is **required**. WhiteBIT sends an invitation to that email, and the sub-account stays inactive until the end user opens the link and sets a password.
- When `shareKyc` is `true`: leave `email` out. The sub-account is active as soon as the request succeeds and shares the main account's verification.
- A request with `email` starts the invitation flow even when `shareKyc` is `true`.
</Note>
