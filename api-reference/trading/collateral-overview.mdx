Collateral trading enables leveraged trading using margin. Manage the collateral account balance, place various order types (limit, market, stop-limit, OCO), modify and query open orders, and manage positions.

For general API conventions (base URL, error format, rate limits), see the [API Reference Overview](/api-reference/overview).

Order modification uses the shared `POST /api/v4/order/modify` endpoint. There is no
collateral-specific path; the `market` parameter identifies which market the order belongs
to.

Group legs are the exception. To change an OCO or OTO leg, cancel the group and place a new
one. To change a [TPSL pair](/websocket/order-management/collateral-order-tpsl-place), which
is placed over WebSocket, cancel the leg and attach a new pair.

## Order Queries

trade-fill history are served by shared order-query endpoints that cover spot and futures
